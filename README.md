# AMISEARCH Teacher Hub

## Files
- `teacher-hub.html`: connected Teacher Hub at `/teacher-hub`
- `preview.html`: faithful visual preview at `/preview`
- `supabase-schema.sql`: tables, trigger, RLS policies, and Storage policies
- `_redirects` and `netlify.toml`: Netlify route configuration

## Deploy
1. Run `supabase-schema.sql` in Supabase SQL Editor.
2. Commit and push this folder to GitHub.
3. Connect the repository to Netlify with publish directory `amisearch-teacher-hub`, or set the repository root to this folder.
